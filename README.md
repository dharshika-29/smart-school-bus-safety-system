# Smart School Bus Safety System

## Project Description

Smart School Bus Safety System is a web and mobile-based system designed to improve school bus safety and provide real-time bus tracking and notifications to parents.

## Key Features

- Parent can track the school bus location
- Driver can update the bus location
- Admin can manage buses, drivers and students
- Parents receive bus notifications and alerts
- Attendance management
- Route management
- Emergency alerts
- Real-time location tracking

## Technology Stack

- Frontend: React
- Backend: Spring Boot
- Database: MySQL
- Maps: Google Maps API
- Notifications: Firebase Cloud Messaging
- Version Control: Git & GitHub

## System Modules

1. Parent Mobile App
2. Driver Mobile App
3. Admin Web Portal
4. React Web Application
5. Spring Boot Backend API
6. MySQL Database
7. Google Maps API
8. Firebase Cloud Messaging

## Project Objective

The main objective is to improve student safety during school transportation by providing real-time bus tracking, notifications, attendance monitoring and emergency alerts.
